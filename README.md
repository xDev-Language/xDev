# xDev

xDev is a general-purpose programming language that combines the procedural and object-oriented paradigms, based on [xBase](https://en.wikipedia.org/wiki/XBase) syntax. The xDev compiler produces native executables directly: machine code is generated by [LLVM](https://llvm.org/) and linked by the [LLD](https://lld.llvm.org/) linker. As a result, xDev inherits the portability of LLVM and can be ported to any platform that LLVM supports. It also benefits from LLVM's multi-pass code optimizations.

A statically and dynamically typed language for building efficient, modern applications, with built-in data types.

```xBase
PROCEDURE Main()

   LOCAL cProgram     := "+ + * 😃 - /"
   LOCAL nAccumulator := 0
   LOCAL cToken
   LOCAL i AS int

   FOR i := 1 TO ULen( cProgram )
      cToken := USubStr( cProgram, i, 1 )
      DO CASE
      CASE cToken == "+"
         nAccumulator += 1
      CASE cToken == "-"
         nAccumulator -= 1
      CASE cToken == "*"
         nAccumulator *= 2
      CASE cToken == "/"
         nAccumulator /= 2
      CASE cToken == "😃"
         nAccumulator *= nAccumulator
      ENDCASE
   NEXT

   QOut( 'The program "' + cProgram + '" calculates the value ' + LTrim( Str( nAccumulator ) ) )

   RETURN

```

Everything you need is included in the package, there is nothing else to install.
Libraries in `lib/xdev` are linked automatically.
