# xDev

xDev is a programming language with
[xBase](https://en.wikipedia.org/wiki/XBase)
syntax and a compiler that turns
`.prg` files into native executables. Machine code is generated by
[LLVM](https://llvm.org/) and linked by the built-in [LLD](https://lld.llvm.org/).

Types are optional; a type declared with `AS` gives faster code and checks at compile time:

```xdev
LOCAL xValue                         // any type
LOCAL nCount AS int                  // integer, checked at compile time
FUNCTION Sum( a AS int, b AS int ) AS int
```

The project is under development (version 0.0.0).

## Requirements

Windows 10 or later, 64-bit.

## Installation

1. Download `xDev-…-win64.zip` from [Releases](https://github.com/xDev-Language/xDev/releases).
2. Unzip it to `C:\`; this creates `C:\xDev`.
3. Add `C:\xDev\bin` to the PATH environment variable.

## First program

`hello.prg`:

```xdev
PROCEDURE Main()
   QOut( "Hello, world!" )
   RETURN
```

```bat
xdev hello.prg
hello.exe
```

## Examples

```bat
cd C:\xDev\examples
xdev -each *.prg
```

## Included libraries

Screen: GTWVT, GTSDL3, GTGLFW · windows: GUI · text mode: TUI (TBrowse, Get, DBEdit) ·
DBF databases · XML · PDF · QR codes · curl · OpenSSL · zlib

Everything is included in the package; nothing else needs to be installed. Libraries in
`lib/xdev` are linked automatically.
